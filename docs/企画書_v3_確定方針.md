## 2. 検品なし前提の品質保証設計(本企画の生命線)

専門家チェックができない以上、**「間違いにくい形式だけを扱う」+「機械的な照合で担保する」**の二段構え。

### 原則: 扱う情報のレベルを制限する

- ◎ 扱う: 単語 ⇔ 定訳(accounts receivable = 売掛金)。辞書・公開用語集で機械的に照合可能
- ○ 限定的に扱う: 短い例文(平易な構文のみ)
- ✕ 扱わない: 制度・法律・会計基準の**解説**、試験対策上の**アドバイス**、条項の**法的効力の説明**(v2案の「shall/mayの効力の違い」「契約の落とし穴事例集」等は解説を含むため**取り下げ**)

### 照合パイプライン(2026-07-09 緩和改訂)

情報レベルを「単語⇔定訳」に制限していることを前提に、照合の厳格さは緩和する。

1. 用語リストは公開ソースから採取(AICPA用語集、IFRS用語集、金融庁・法務省の公表対訳、一般辞書)
2. 訳語の不一致・揺れは、**判断・修正して採用してよい**(旧ルールの「不一致は一律収録しない」は廃止)
3. LLM生成物のクロスチェックは維持: 別セッション・別プロンプトで検証し、疑義が残るものだけ除外
4. 巻頭・巻末に免責(学習用であり専門的助言ではない)を記載。誤植報告フォームは設けない

## 3. 単語DB設計

CSV 1ファイル/ニッチ(将来SQLite化可能な素直なスキーマ)。

| 列 | 内容 |
|---|---|
| id | 連番 |
| subject | 科目・分野タグ(FAR/AUD/REG/BEC、契約書/会社法 等) |
| term | 英語 |
| meaning_ja | 定訳(1行。解説は書かない) |
| example_en | 短い例文(任意。平易な構文のみ) |
| example_ja | 例文の和訳(任意) |
| source | 照合したソース(セミコロン区切りで2つ以上) |
| status | draft / verified / rejected |
| used_at | SNS投稿に使用した日付(未使用は空欄) |

- 実ファイル: `data/uscpa_words.csv`(**完成版1,000語・全語に対訳例文付き。2026-07-09 完了**)、`data/legal_words.csv`(**完成版1,000語・全語に対訳例文付き。2026-07-09 完了**)
- 法律英語DBの科目タグ(10分野): CONTRACT 契約総論 200 / CLAUSE 契約定型表現 180 / CORP 会社法 120 / LIT 訴訟 130 / CRIM 刑事 50 / GEN 法一般・ラテン語 30 / IP 知的財産 80 / EMP 労働 70 / FIN 金融・担保 90 / PROP 不動産 50
- 法律英語の展開順: 英文契約書(CONTRACT+CLAUSE=380語)を第1弾のSNS・Kindleに使用し、CORP/LIT等は「法律学習者向け」拡張の第2弾以降に回す
- 法律英語DBも機械検証済み: 全1,000行がフィールド数9・例文欠損ゼロ・用語重複ゼロ・id連番1〜1000(追加は1001以降)
- 科目構成は現行試験(2024年 CPA Evolution 以降)に準拠: **コア = FAR / AUD / REG、選択 = BAR / ISC / TCP**(旧BECは廃止済みのため使用しない)
- 完成版の内訳: FAR 330 / AUD 160 / REG 200 / BAR 120 / ISC 90 / TCP 100(計1,000語)
- 例文は全語必須(平易な構文・1文・15語以内目安)。Kindleの「例文つき単語帳」がこの列をそのまま使う
- 用語の重複は科目間で意味が異なる場合のみ許容(現状は authorization のみ: AUD=承認 / ISC=権限付与)
- 機械検証済み: 全1,000行がフィールド数9・例文欠損ゼロ・id連番1〜1000
- 今後の追加は id 1001 以降に追記(既存idは不変。Kindle章立て・SNS投稿履歴がidを参照するため)

## 4. SNS投稿定型(確定フォーマット)

1投稿 = 同一科目から3語。DBから status=verified かつ used_at が古い順に取り出して整形するだけ。

```
【USCPA英単語 #FAR】

accounts receivable
└ 売掛金

accrued expenses
└ 未払費用

deferred revenue
└ 前受収益

毎日3語ずつ。まとめはKindleで📚(リンク)
```

- 1日2〜3投稿(朝7時・昼12時・夜21時)、科目をローテーション
- 全語出し切ったら先頭から再利用(単語帳系は繰り返しがむしろ歓迎される)
- クイズ等の変則投稿は当面やらない。定型リストに一本化し、運用を完全自動化しやすくする

## 5. Kindleラインナップ(検品不能を考慮した改訂版)

v2の15案から、解説・専門的判断を含む案を落とし、**「対訳」という既存ブランドの強みに寄せる**。

### USCPAシリーズ
1. **科目別頻出英単語(FAR/AUD/REG/BEC の4冊)**: term+定訳のリスト構成。主力。1冊500〜980円
2. **USCPA英単語 全科目チェック版**: 4冊のダイジェスト+全語索引。入口用の薄い本(250円 or 無料キャンペーン用)
3. **例文つき単語帳**: 平易な例文+対訳。既存の対訳出版のノウハウがそのまま活きる

### 法律英語シリーズ(英文契約書スタート)
4. **英文契約書の頻出単語・定型句リスト**: 用語と定訳のみ。「条項の意味の解説」はしない
5. **対訳で読む契約書表現**: 公開されているモデル契約書等の定型表現を対訳リスト化
6. (将来・拡張)法律学習者向け: 会社法・民法系の英語用語集など、公表対訳が存在する分野から順に

### 読み物系(対訳ブランドの延長)
7. **対訳で読む会計・商業の古典**(版権切れ): 既存事業とニッチの橋渡し。例: 商業・経済を題材にした著作の対訳+巻末に関連英単語リスト。物語の「創作」をしないので品質リスクが低い

※ 取り下げ: 音声付き(不要と決定)、ストーリー創作もの・落とし穴事例集・矯正ドリル(解説の正確性を担保できない)

## 6. 運用フロー(確定版)

```
公開ソースから用語採取
  → LLMで整形+訳語候補付け(draft)
  → 2ソース照合+別セッション検証 → verified / rejected
  → uscpa_words.csv に確定格納
  ├→ SNS: 定型テンプレに流し込み、スケジューラで自動投稿(used_at 更新)
  └→ Kindle: 科目別に章立て・組版 → EPUB
```
