# 中級〜上級者向け英語学習教材 企画書(初版)

作成日: 2026-07-09

## 1. ターゲット設定

- レベル: CEFR B2〜C1(TOEIC 800+ / 英検準1級〜1級を目指す層)
- この層の特徴的な悩み:
  - 「読める・聞けるが、自然な英語が出てこない」(受動→能動のギャップ)
  - 教科書英語とネイティブの実際の表現の乖離
  - 単語は知っているがコロケーション・ニュアンスの使い分けができない
  - 中級向け教材は簡単すぎ、洋書・海外メディアはハードルが高い「教材の空白地帯」
- ペルソナ例: 30代前後の社会人。仕事で英語を使う機会があり、独学継続中。X で英語学習アカウントをフォローしている。

## 2. 教材コンセプト案

### 案A(推奨): 「ニュアンス・言い換え特化」教材
- 「知ってる単語を、ネイティブらしく使い分ける」に全振り
- 例: *big / large / huge / massive* の使い分け、*I think* の言い換え 12 パターン、フォーマル度スケール付き類語辞典
- 強み: SNS 投稿との相性が最高(1投稿=1ネタで無限に切り出せる)。競合の「単語帳」「文法書」と差別化しやすい

### 案B: 「英語ニュース読解+語彙」教材
- 実際の英字メディア頻出表現を体系化。時事ネタで鮮度を出せるが、更新コストが高い

### 案C: 「アウトプット矯正」教材
- 日本人がやりがちな不自然な英語 → 自然な英語への書き換えドリル
- 案Aと親和性が高く、第2弾商品として有力

### 商品形態(段階的に展開)
1. 無料: SNS 投稿 + 無料PDF(リード獲得用、例:「言い換え表現100」)
2. 低価格帯: note / PDF 教材(500〜1,500円)
3. 中価格帯: メール講座 or 体系化した電子書籍(3,000〜5,000円)

## 3. SNS BOT運用設計

### プラットフォーム
- 主軸: X(旧Twitter)。英語学習アカウント文化が最も成熟しており、テキスト主体でBOT運用と相性が良い
- 補助: Instagram(画像カルーセル化した同一コンテンツの転用)。後回しで可

### 投稿カテゴリ(曜日ローテーション例)

| カテゴリ | 内容 | 例 |
|---|---|---|
| 使い分け | 類語のニュアンス比較 | 「"almost" と "nearly" の違い、説明できますか?」 |
| 言い換え | 中学英語→こなれた表現 | 「"very tired" 卒業 → exhausted / drained / wiped out」 |
| クイズ | 4択・穴埋め(エンゲージメント向け) | 「ネイティブが選ぶのはどっち? (a) do a mistake (b) make a mistake」 |
| 日本人あるある | 不自然な英語の矯正 | 「"I have a promise" は通じない。正解は "I have plans"」 |
| 1行フレーズ | 保存されやすい実用表現 | 「会議で使える "Let me push back on that a little."」 |

### 投稿サンプル(そのまま使えるレベルの具体例)

```
「怒っている」のグラデーション🌡️

annoyed     イラッとした
irritated   イライラしてる
angry       怒っている
furious     激怒している
livid       怒りで我を忘れるレベル

"She was livid." と言われたら謝罪一択です
```

```
"I think" ばかり使っていませんか?

確信度 低 → 高
I guess...        たぶんね(軽い)
I suppose...      まあそうかな
I think...        そう思う
I believe...      そう信じている
I'm convinced...  確信している

明日から1つ置き換えてみてください
```

### 運用パラメータ
- 頻度: 1日 2〜3 投稿(朝7時台・昼12時台・夜21時台 = 通勤・昼休み・就寝前)
- クイズは出題→翌日回答の2段構成でリプ・再訪を誘発
- 完全自動化はせず「生成は自動、公開前レビューは人間」から始める(誤った英語を BOT が拡散すると信頼が致命傷になるため)

### BOT の技術構成(想定)
1. コンテンツDB: 投稿ネタを CSV / JSON でストック(カテゴリ・本文・使用済みフラグ)
2. 生成: Claude API でネタ候補を量産 → 人間が検品して DB に追加
3. 投稿: X API v2(Basic プラン、月100ドル。無料プランは投稿数制限が厳しい点に注意)+ スケジューラ(GitHub Actions cron / タスクスケジューラ)
4. 分析: インプレッション・保存数をカテゴリ別に集計し、伸びるカテゴリに投稿比率を寄せる

### 集客導線
X 投稿(認知)→ プロフィール固定ツイート → 無料PDF配布(メールアドレス取得)→ メールで教材販売へ誘導
