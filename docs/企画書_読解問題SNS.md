# 企画書: 英文読解・英文解釈問題SNS(中上級者向け)

作成日: 2026-07-10(単語DB企画〔企画書_v3〕の姉妹コンテンツ)

## 1. コンセプト

- ターゲット: CEFR **B2〜C2**(英検準1級〜1級超)。「単語は知っているが複雑な構文が正確に読めない」層
- 1投稿=1問の英文解釈問題。倒置・省略・比較・連鎖関係詞・仮定法など、構造が読めるかを問う「良問」に絞る
- 英文は**全問オリジナル作文**(引用なし=著作権リスクゼロ。既存の品質方針と整合)
- 出題テーマは固定しない。categoryは自由記述タグで、語法・多義語・文脈推測・パラフレーズ等いつでも拡張可

## 2. データベース

実ファイル: `data/reading_problems.jsonl`(1行=1問のJSON。将来SQLite化可能)

| フィールド | 内容 |
|---|---|
| id | 連番(既存DB同様、id不変・追記は末尾) |
| category | 分類タグ(自由記述) |
| point | 文法・構文ポイント(例: 連鎖関係詞節、not so much A as B) |
| difficulty | 1=B2(準1級)/ 2=C1(1級)/ 3=C2(1級超) |
| format | quiz(選択式)/ translation(和訳) |
| sentence_en | 出題英文(オリジナル、1〜2文) |
| question_ja | 問い |
| choices / answer_index | 選択肢と正解添字(translationは[]/null) |
| translation_ja | 全訳 |
| explanation_ja | 解説(構造分解・着眼点・訳出のコツ。150〜250字) |
| status | draft / verified / rejected |
| used_at | 投稿使用日(未使用は空欄) |

ストック(2026-07-10 時点): **200問・機械検証済み**(全行パース・必須フィールド・id連番1〜200・quiz整合・全投稿280字以内)。

構成の考え方(2層):
1. **構文解釈 150問(id 1〜150)**: 英文解釈の主要構文パターン約100〜120(定番教材の合計がカバーする範囲)を網羅+頻出パターンの複数バリエーション。「すらすら読める」には網羅+同一パターンへの反復接触が必要で、反復は投稿ローテーションの再利用が担う
2. **読解スキル 50問(id 151〜200)**: 構文が取れた先でつまずく技能 — 指示語・照応8 / 文脈推測(未知語の意味推測)8 / パラフレーズ(nothing if notなど字面と意味がズレる表現)8 / 談話・論理展開(譲歩→主張、Indeedの機能)8 / 構造の罠(接触節のガーデンパス)8 / トーン・皮肉5 / 情報構造5

全体 — 難易度: B2 62 / C1 109 / C2 29。形式: quiz 60 / translation 140。全問 status=draft。

## 3. 投稿フォーマット(ツリー形式)

1問=1ツリー。出題ポストに解説リプライをぶら下げる(翌日回答方式は採らない)。

```
① 出題ポスト
【英文解釈 No.13|倒置・強調】(難易度 B2)

Not until the final chapter does the author reveal
what the title really means.

Q. 主節の主語は?
A) the final chapter
B) the author
C) the title

↓答えと解説はリプ欄に
#英文解釈 #英語学習

② リプライ1: 正解+全訳
③ リプライ2: 【解説】構造のポイント(短ければ②に統合)
```

- 全投稿が X の280字(全角2・半角1換算)以内であることをスクリプトで機械チェック済み
- 整形は `scripts/format_reading_post.py` で自動化:
  - 引数なし → 未使用で最も古い1問をツリー形式で出力
  - `--id N` 指定出力 / `--validate` 機械検証 / `--stats` 集計 / `--mark-used N` 使用日記録

## 4. 品質保証(検品なし前提)

単語DBのパイプラインを踏襲しつつ、解説を含むため一段厳しくする。

1. 英文はオリジナル作文のみ。解説は構文事実(倒置・省略・品詞判定・節の完全/不完全)に限定し、規範的な語法論争や試験対策アドバイスには踏み込まない
2. status=draft で格納 → **別セッション・別プロンプトでのクロスチェック**(英文の自然さ/正解の一意性/解説の正確さ)を通過したものだけ verified 化
3. quiz は「正解が一意に決まるか」を最優先で検証。両義性が残る問題は、両義性自体を問う形(No.25 not...because)にするか rejected
4. 投稿時に免責は不要だが、プロフィール等に学習用コンテンツである旨を明記

## 5. 運用

- 投稿頻度: 1日1〜2ツリー(単語投稿と時間帯を分ける。例: 単語=朝昼、解釈=夜21時)
- used_at の古い順に消化。全問出し切ったら先頭から再利用可(構文問題も繰り返し歓迎される)
- エンゲージメント: quiz形式(全体の約1/3)はリプ・引用で回答が付きやすい。伸びたカテゴリに増産を寄せる
- Kindle展開: 「カテゴリ別・英文解釈トレーニング」として章立て可能(explanation_jaがそのまま本文になる)
